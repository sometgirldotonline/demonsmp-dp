# Demon SMP Datapack 
![Hackatime Hours Badge](https://hackatime.hackclub.com/api/v1/badge/U09JWS88XU0/sometgirldotonline/demonsmp-dp) *◀️ that's how many hours i've spent on this*

**Version:** Minecraft Java 26.1.2

Adds some skills to minecraft. Skill names are pretty verbose because they're intended to be triggered using a mod that binds commands to keyboard shortcuts.

## Rays
There are three types of rays currently:
<ul>
  <li><b>Blindness Ray</b><br>
    <pre><code>/function demonsmp:skills/blind</code></pre>
    Inflicts target with:
  <ul>
    <li>Blindness L256, for 10 seconds</li>
    <li>Darkness L256, for 10 seconds</li>
  </ul></li>
    <li><b>Glowing Ray</b><br>
    <pre><code>/function demonsmp:skills/glow</code></pre>
    Inflicts target with:
  <ul>
    <li>Glowing, for 10 seconds</li>
  </ul></li>
    <li><b>Wither Ray</b><br>
    <pre><code>/function demonsmp:skills/wither</code></pre>
    Inflicts target with:
  <ul>
    <li>Wither L2, for 3 seconds</li>
  </ul></li>
</ul>
Will have some item assigned to each, not sure which items to use as base for each yet, or the crafting.
